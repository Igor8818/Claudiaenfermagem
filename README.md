### 🛠️ Como Executar Localmente
O projeto já conta com um servidor HTTP leve sem necessidade de instalar pacotes externos:

```bash
# Iniciar o servidor local
npm start
# ou
node server.js
```

Em seguida, abra o navegador em:
👉 **`http://localhost:3000`**

Você também pode simplesmente dar um duplo clique no arquivo [`index.html`](file:///c:/Users/igor/claudiaenf/index.html) para abrir diretamente em qualquer navegador!
